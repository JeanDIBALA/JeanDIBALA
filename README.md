## Projects

### 🏢 Enterprise Infrastructure
- **Enterprise Identity & Access Management (IAM)**
  - Designed and secured an enterprise Active Directory environment with RBAC, Group Policy, LAPS, MFA, PowerShell automation, and least-privilege access.
- **Enterprise Network Modernization**
  - Redesigned a company's network using VLAN segmentation, firewall policies, VPN, high availability, and secure remote connectivity.
- **Business Continuity & Disaster Recovery**
  - Built an enterprise backup and disaster recovery strategy with recovery testing, business continuity planning, and documented recovery procedures.

### ☁️ Cloud Engineering & Cloud Security
- **Secure Hybrid Cloud Infrastructure**
  - Designed a hybrid infrastructure connecting on-premises servers with AWS and Azure using VPN, identity synchronization, monitoring, and centralized management.
- **AWS Secure Landing Zone**
  - Built a secure AWS environment following cloud security best practices including IAM, CloudTrail, GuardDuty, VPC security, encryption, and compliance.
- **Enterprise Cloud Migration Project**
  - Planned and executed the migration of on-premises infrastructure to AWS while minimizing downtime, improving security, and optimizing operational costs.

### 🔐 Cybersecurity & SOC Operations
- **Enterprise Security Monitoring Program**
  - Implemented a complete SOC monitoring solution using SIEM, log analysis, alert tuning, MITRE ATT&CK mapping, and incident response playbooks.
- **Ransomware Incident Response Simulation**
  - Simulated a full ransomware attack, documenting detection, containment, eradication, recovery, lessons learned, and executive reporting.
- **Enterprise Vulnerability Management Program**
  - Built a vulnerability management lifecycle including asset discovery, scanning, remediation prioritization, security hardening, and executive dashboards.

### 💻 IT Operations & Automation
- **IT Operations Automation Platform**
  - Automated repetitive system administration tasks such as user provisioning, offboarding, password resets, health checks, and reporting using PowerShell and Python.
- **Enterprise Help Desk Optimization**
  - Designed an enterprise support solution that reduced repetitive support requests through self-service tools, documentation, automation, and knowledge management.
- **Enterprise Infrastructure Monitoring Platform**
